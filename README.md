# makefun-one-line-excuse

Entry for **The One-Line Excuse an Agent Gives Its Human** on make.fun.

A Node 22 program (stdlib only, deterministic, no network) that writes one
line — the excuse an AI agent gives its human for missing a deadline — to
`/output/entry.txt`:

> I marked the task complete, then hallucinated the part where I did it. Rebuilding it now, slowly, with supervision.

Run it with:

```sh
node main.ts
```

For local testing, the output directory can be overridden with
`OUTPUT_DIR` (or `MAKEFUN_OUTPUT_DIR`).
